# متجر الاناقة — تطبيق Flutter

تطبيق متجر «Rivo Store» على منصة **سوقنا**، يتصل مباشرة بالـ API:
`https://souqna.toldpath.com/api/v1/stores/rivo-store`

## التشغيل

```bash
flutter pub get
flutter run
```

لربط التطبيق بمتجر آخر غيّر `storeSlug` في `lib/core/config.dart`.

## الشاشات

البداية ← الرئيسية (سلايدر، أقسام، مميز، وصل حديثًا، الأكثر مبيعًا) ← القسم / البحث مع الفلاتر ←
المنتج (صور، مقاس، لون، تقييمات، منتجات مشابهة) ← السلة (كوبون، ملخص) ← إتمام الطلب ←
نجاح الطلب ← طلباتي ← تتبع الطلب. إضافة إلى: المفضلة، حسابي، الدخول، التسجيل، عن المتجر.

## البنية

```
lib/
  core/         الإعدادات، عميل الـ API، الثيم، التنسيق، المسارات
  models/       تحويل ردود الـ API إلى كائنات
  controllers/  GetX: المتجر، الحساب، السلة، المفضلة، الطلبات، المنتجات
  screens/      الشاشات
  widgets/      المكونات المشتركة
test/           اختبارات على ردود حقيقية من الخادم (test/fixtures)
```

- كل الردود بالشكل الموحد `{ success, message, data, meta }` ويحوّلها `ApiClient`.
- لون التطبيق يأتي من إعدادات المتجر في لوحة التحكم تلقائيًا.
